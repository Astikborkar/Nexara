## 🌐 Overview

**Nexara Revenue OS** is an autonomous revenue infrastructure application engineered to replace manual SDR activity with high-leverage software architecture. It combines AI-driven prospecting, multi-touch omnichannel outbound, zero-latency CRM synchronization, rep productivity copilots, and multi-touch revenue attribution.

---

## ⚡ 7 Core Capability Pillars

1. **AI-Driven Prospecting & Qualification:** Real-time buying intent harvesting (6sense, hiring alerts, tech stack shifts) + 15-parameter LLM fit scoring (0–100).
2. **Automated Omnichannel Outbound:** Multi-touch sequences across Email, LinkedIn, and AI Voice with A/B copy variants and inbound reply sentiment classification.
3. **CRM & Pipeline Architecture:** Zero-latency bi-directional sync (HubSpot & Salesforce) with deterministic stage routing and deal velocity tracking.
4. **Rep Productivity Copilot:** Automated pre-meeting executive briefs, real-time in-call objection surfacing (battlecards), and 1-click follow-up email generation (+18.5 hrs saved/rep/week).
5. **KPI Dashboards & Attribution:** Financial velocity metrics, Chart.js multi-touch attribution doughnut chart, and interactive ARR & CAC payback leverage calculator.
6. **Sales Playbooks & Conversion:** Competitor battlecards, tactical objection script engine, and funnel latency diagnostics.
7. **System Infrastructure Leverage:** Blueprint of autonomous nodes, webhook payload schemas, vector store sync, and LLM proxy orchestration.

## 🛠️ Tech Stack & Local Development

- **Framework:** React 18 + Vite
- **Styling:** Custom Vanilla CSS (Dark Theme, Glassmorphism, Responsive CSS Tokens)
- **Icons & Visuals:** Lucide React, Chart.js, Canvas Confetti
- **Deployment:** GitHub Pages (`gh-pages` branch)

```bash
# Clone the repository
git clone https://github.com/Astikborkar/Nexara.git

# Navigate to project directory
cd Nexara

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open `http://localhost:3000/` in your browser.
